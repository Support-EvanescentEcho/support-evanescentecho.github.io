Installing the desktop apps

The Windows and Linux versions of the Evanescent Echo apps are not digitally signed. This page explains what that means, the warning Windows will show you, and how to check that the file you downloaded is the original.

Why they are not signed. Signing an installer means buying a publisher certificate every year or publishing through a store. I make these apps on my own, they are free and they have no payments, so for now I have chosen not to do either. Being unsigned does not change how your data is protected: it stays encrypted on your device, as explained in Your data and your access. What I cannot give you without a signature is Windows' guarantee of who published the installer. Checking the SHA-256, below, takes its place.

Windows

What you will see

When you open the installer, Windows SmartScreen may show a blue window that says “Windows protected your PC” and “Unknown publisher”. Your browser may also warn that the file is not commonly downloaded. This does not mean the file contains a virus: it means Windows does not know who published it, because it has no signature and few people have downloaded it yet.

How to continue

  1. Download only from the official website of each app or from its release page on GitHub.
  2. Check the file as explained below.
  3. Open the installer. If the warning appears, select “More info” and then “Run anyway”.

You do not need to turn off SmartScreen or your antivirus, and I recommend that you don't. The exact words of the warning can change between versions of Windows.

Check that the file is the original

Without a signature, the way to know that nobody changed the file is to compare its SHA-256 fingerprint with the one shown next to the file on the official release page on GitHub. In PowerShell, in the folder where you saved it:

Get-FileHash .\HoursLived-Setup.exe -Algorithm SHA256

The file names here are an example: use the name of the file you downloaded. If the two values are not identical, do not install it, delete the file and write to me.

Linux

The .deb package is not signed either. Check it the same way before installing it:

sha256sum HoursLived.deb

Then install it with:

sudo apt install ./HoursLived.deb

On Linux the app asks you to choose a password to protect your diary, because Linux has no protected key storage equivalent to the one on Windows. Keep it safe: without it, the data cannot be opened.

Write to me

If a fingerprint does not match, an installer behaves strangely or something on this page is wrong, please write to support.evanescentecho@gmail.com. I read every message myself.

デスクトップ版のインストール

Evanescent Echo のアプリの Windows 版と Linux 版には、デジタル署名がありません。このページでは、それが何を意味するのか、Windows が表示する警告、そしてダウンロードしたファイルが本物かどうかを確認する方法を説明します。

署名していない理由 インストーラーに署名するには、毎年発行元の証明書を購入するか、ストアを通じて公開する必要があります。私はこれらのアプリを一人で作っており、無料で課金もないため、今のところどちらも行わないことにしました。署名がなくても、データの保護方法は変わりません。データとアクセシビリティで説明しているとおり、データはデバイス上で暗号化されたままです。署名なしでは、誰がインストーラーを公開したかという Windows の保証を提供できません。その代わりとなるのが、下の SHA-256 の確認です。

Windows

表示される警告

インストーラーを開くと、Windows SmartScreen が 「WindowsによってPCが保護されました」 と 「不明な発行元」 という青い画面を表示することがあります。ブラウザーも、このファイルはあまりダウンロードされていないと警告する場合があります。これはファイルにウイルスが含まれているという意味ではありません。署名がなく、まだダウンロードした人が少ないため、Windows が発行元を判断できないということです。

続行する方法

  1. 各アプリの公式サイト、または GitHub のリリースページからのみダウンロードしてください。
  2. 下の説明に従ってファイルを確認してください。
  3. インストーラーを開きます。警告が表示されたら 「詳細情報」 を選び、次に 「実行」 を選びます。

SmartScreen やウイルス対策ソフトを無効にする必要はなく、無効にしないことをおすすめします。警告の正確な文言は Windows のバージョンによって異なる場合があります。

ファイルが本物か確認する

署名がない場合、誰もファイルを改変していないことを確かめるには、その SHA-256 フィンガープリントを、GitHub の公式リリースページでファイルの横に表示されている値と比べます。保存したフォルダーで、PowerShell を使って次を実行します。

Get-FileHash .\HoursLived-Setup.exe -Algorithm SHA256

ファイル名は例です。ダウンロードしたファイルの名前に置き換えてください。 2つの値が完全に一致しない場合は、インストールせずにファイルを削除し、私に連絡してください。

Linux

.deb パッケージにも署名はありません。インストールする前に、同じ方法で確認してください。

sha256sum HoursLived.deb

その後、次のコマンドでインストールします。

sudo apt install ./HoursLived.deb

Linux では、日記を保護するためのパスワードを決めるようアプリが求めます。Linux には Windows のような保護されたキー保存領域がないためです。大切に保管してください。パスワードがないとデータを開けません。

ご連絡ください

フィンガープリントが一致しない、インストーラーの動作がおかしい、このページの内容が間違っているなどの場合は、support.evanescentecho@gmail.com までご連絡ください。すべてのメッセージに私自身が目を通します。

데스크톱 앱 설치하기

Evanescent Echo 앱의 Windows 및 Linux 버전에는 디지털 서명이 없습니다. 이 페이지에서는 그것이 무엇을 의미하는지, Windows가 보여 줄 경고, 그리고 내려받은 파일이 원본인지 확인하는 방법을 설명합니다.

서명하지 않는 이유. 설치 프로그램에 서명하려면 매년 게시자 인증서를 구입하거나 스토어를 통해 배포해야 합니다. 저는 이 앱들을 혼자 만들고 있고, 앱은 무료이며 결제 기능도 없기 때문에 지금은 둘 다 하지 않기로 했습니다. 서명이 없어도 데이터가 보호되는 방식은 달라지지 않습니다. 데이터와 접근성에서 설명하듯이 데이터는 기기에 암호화된 채로 남아 있습니다. 서명 없이는 누가 설치 프로그램을 게시했는지에 대한 Windows의 보증을 드릴 수 없습니다. 아래의 SHA-256 확인이 그 역할을 대신합니다.

Windows

보게 될 화면

설치 프로그램을 열면 Windows SmartScreen이 “Windows의 PC 보호”와 “알 수 없는 게시자”라고 표시된 파란 창을 보여 줄 수 있습니다. 브라우저도 이 파일이 자주 다운로드되지 않는다고 경고할 수 있습니다. 이는 파일에 바이러스가 있다는 뜻이 아닙니다. 서명이 없고 아직 내려받은 사람이 적어서 Windows가 게시자를 알 수 없다는 뜻입니다.

계속하는 방법

  1. 각 앱의 공식 웹사이트나 GitHub의 릴리스 페이지에서만 내려받으세요.
  2. 아래 설명대로 파일을 확인하세요.
  3. 설치 프로그램을 엽니다. 경고가 나타나면 “추가 정보”를 선택한 다음 “실행”을 선택하세요.

SmartScreen이나 백신 프로그램을 끌 필요는 없으며, 끄지 않기를 권합니다. 경고 문구는 Windows 버전에 따라 다를 수 있습니다.

파일이 원본인지 확인하기

서명이 없을 때 아무도 파일을 바꾸지 않았는지 확인하는 방법은 파일의 SHA-256 지문을 GitHub 공식 릴리스 페이지에서 파일 옆에 표시된 값과 비교하는 것입니다. 파일을 저장한 폴더에서 PowerShell로 다음을 실행하세요.

Get-FileHash .\HoursLived-Setup.exe -Algorithm SHA256

파일 이름은 예시입니다. 내려받은 파일의 이름을 사용하세요. 두 값이 정확히 같지 않으면 설치하지 말고 파일을 삭제한 뒤 저에게 알려 주세요.

.deb 패키지도 서명되어 있지 않습니다. 설치하기 전에 같은 방법으로 확인하세요.

그런 다음 다음 명령으로 설치합니다.

Linux에서는 일기를 보호할 비밀번호를 정하라고 앱이 요청합니다. Linux에는 Windows와 같은 보호된 키 저장소가 없기 때문입니다. 잘 보관하세요. 비밀번호가 없으면 데이터를 열 수 없습니다.

Установка версий для компьютера

Версии приложений Evanescent Echo для Windows и Linux не имеют цифровой подписи. На этой странице объясняется, что это значит, какое предупреждение покажет Windows и как проверить, что скачанный файл — оригинальный.

Почему они не подписаны. Чтобы подписать установщик, нужно каждый год покупать сертификат издателя или публиковать приложение через магазин. Я делаю эти приложения один, они бесплатные и без платежей, поэтому пока решил не делать ни того, ни другого. Отсутствие подписи не меняет того, как защищены ваши данные: они по-прежнему зашифрованы на вашем устройстве, как описано на странице Ваши данные и доступность. Без подписи я не могу дать вам гарантию Windows о том, кто опубликовал установщик. Её заменяет проверка SHA-256, описанная ниже.

Windows

Что вы увидите

При запуске установщика Windows SmartScreen может показать синее окно с надписями «Система Windows защитила ваш компьютер» и «Неизвестный издатель». Браузер тоже может предупредить, что файл скачивают редко. Это не значит, что в файле вирус: просто Windows не знает, кто его опубликовал, потому что у файла нет подписи и его пока скачали немногие.

Как продолжить

  1. Скачивайте только с официального сайта приложения или с его страницы выпусков на GitHub.
  2. Проверьте файл, как описано ниже.
  3. Запустите установщик. Если появится предупреждение, нажмите «Подробнее», а затем «Выполнить в любом случае».

Отключать SmartScreen или антивирус не нужно, и я не советую этого делать. Точный текст предупреждения может отличаться в разных версиях Windows.

Проверьте, что файл оригинальный

Без подписи убедиться, что файл никто не изменял, можно, сравнив его отпечаток SHA-256 с тем, что указан рядом с файлом на официальной странице выпусков на GitHub. В PowerShell, в папке, куда вы его сохранили:

Get-FileHash .\HoursLived-Setup.exe -Algorithm SHA256

Имена файлов приведены для примера: укажите имя скачанного файла. Если значения не совпадают полностью, не устанавливайте его, удалите файл и напишите мне.

Linux

Пакет .deb тоже не подписан. Проверьте его так же перед установкой:

sha256sum HoursLived.deb

Затем установите его командой:

sudo apt install ./HoursLived.deb

В Linux приложение попросит вас придумать пароль для защиты дневника, потому что в Linux нет защищённого хранилища ключей, как в Windows. Храните его надёжно: без него данные открыть нельзя.

安装桌面版应用

Evanescent Echo 应用的 Windows 版和 Linux 版没有数字签名。本页说明这意味着什么、Windows 会显示什么警告，以及如何确认你下载的文件是原始文件。

为什么没有签名。 为安装程序签名，需要每年购买发布者证书，或通过应用商店发布。这些应用由我独自制作，免费且没有任何付费功能，所以目前我选择两者都不做。没有签名并不会改变你的数据受保护的方式：数据仍然加密保存在你的设备上，详见你的数据与无障碍。没有签名，我就无法提供 Windows 对安装程序发布者的担保。下面的 SHA-256 校验可以代替它。

Windows

你会看到什么

打开安装程序时，Windows SmartScreen 可能会显示一个蓝色窗口，写着“Windows 已保护你的电脑”和“未知发布者”。浏览器也可能提示该文件不常被下载。这并不表示文件含有病毒，而是因为它没有签名、下载的人还不多，Windows 无法确认发布者是谁。

如何继续

  1. 只从各应用的官方网站或其 GitHub 发布页面下载。
  2. 按照下文说明校验文件。
  3. 打开安装程序。如果出现警告，请选择“更多信息”，然后选择“仍要运行”。

你不需要关闭 SmartScreen 或杀毒软件，我也建议不要关闭。警告的具体文字可能因 Windows 版本而异。

确认文件是原始文件

没有签名时，确认文件未被他人修改的方法，是将它的 SHA-256 指纹与 GitHub 官方发布页面上文件旁显示的值进行比较。在保存文件的文件夹中，用 PowerShell 运行：

Get-FileHash .\HoursLived-Setup.exe -Algorithm SHA256

文件名仅为示例：请换成你下载的文件名。 如果两个值不完全相同，请不要安装，删除该文件并写信告诉我。

Linux

.deb 软件包同样没有签名。安装前请用同样的方法校验：

sha256sum HoursLived.deb

然后用以下命令安装：

sudo apt install ./HoursLived.deb

在 Linux 上，应用会请你设置一个密码来保护你的日记，因为 Linux 没有与 Windows 相当的受保护密钥存储。请妥善保管：没有它，数据就无法打开。

写信给我

如果指纹不一致、安装程序行为异常，或本页内容有误，请写信到 support.evanescentecho@gmail.com。每一封信我都会亲自阅读。
