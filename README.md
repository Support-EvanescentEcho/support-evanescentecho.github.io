# Evanescent Echo — Official Studio Portal

Source code for the official umbrella portal and brand landing page of **Evanescent Echo** (`https://support-evanescentecho.github.io/`).

## Architectural Role

This repository serves as the central hub connecting all independent project websites in the Evanescent Echo ecosystem:

- **Portal Home:** `https://support-evanescentecho.github.io/`
- **Hours Lived Web:** `https://support-evanescentecho.github.io/hours-lived-web/`
- **Echoes of Them Web:** `https://support-evanescentecho.github.io/echoes-of-them-web/`

## Tech Stack

- **Framework:** Vanilla HTML5, CSS3, Vanilla JavaScript (Zero external dependencies or bundlers).
- **Typography:** Cormorant Garamond & Inter (Google Fonts).
- **Hosting:** GitHub Pages root user/organization repository (`support-evanescentecho.github.io`).
